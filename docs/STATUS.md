### Текущий функциональный статус
- Плагин: **реализован как начальный прототип; в RPG Maker MZ ещё не запускался**.
- Сервер: **реализован как начальный прототип; фактическое соединение двух игровых клиентов ещё не проверено**.
- Unit-тесты протокола: добавлены; результат локального запуска должен быть указан отдельной записью после выполнения.
- CI: настроен; статус GitHub Actions должен быть проверен после первого запуска.

### Известные ограничения
- Поддерживается только видимость удалённого игрока и пересылка положения/графики.
- Не синхронизируются события, сюжет, бои, враги, предметы, здоровье, опыт, инвентарь, переменные, переключатели или сохранения.
- Сервер не имеет TLS или аутентификации. По умолчанию слушает только loopback, это прототип для локальных тестов.
- В редакторе MZ ещё не проверено появление второго персонажа, интерполяция движения, повторное подключение и перенос между картами.
