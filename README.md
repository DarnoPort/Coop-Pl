# Coop-Pl — кооперативный плагин для RPG Maker MZ

Проект сетевого кооператива для RPG Maker MZ. Код плагина и сервер размещаются отдельно от файлов конкретной игры.

## Текущий прототип

1. Подключение к серверу комнаты по WebSocket.
2. Видимый персонаж другого игрока на той же карте, передача позиции, направления и графики.
3. Комнаты с назначением хоста, обработкой входа и выхода, переподключением.
4. Host-authoritative синхронизация общих переключателей и JSON-примитивных переменных.
5. Автоматические тесты серверной комнаты, проверки сетевого протокола и базового поведения плагина в mock-runtime.

Код всё ещё является прототипом, не готовым кооперативным релизом. Автоматические тесты успешно прошли на коммите 2a070fc (14/14); позже обновлённая документация также прошла CI. В реальной MZ нужно отдельно проверить синхронизацию switch/variable. Исполнение сюжетных событий, предметы, инвентарь, бои и сохранения пока не синхронизируются.

## Проект для совместимости

Первичный тестовый проект, предоставленный владельцем: **Michael Way – Double Way**, RPG Maker MZ **1.10.0**. В полученном архиве список плагинов пуст, присутствует карта Map001. Игровые данные и ресурсы проекта не копируются в этот репозиторий.

## Структура

- `plugin/` — JavaScript-плагин для RPG Maker MZ.
- `server/` — отдельный Node.js WebSocket-сервер комнат.
- `docs/` — архитектура, этапы, тесты и журнал наблюдений.
- `tests/` — автоматические проверки, которые могут выполняться без ручного запуска редактора.
