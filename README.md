# Coop-Pl — кооперативный плагин для RPG Maker MZ

Проект сетевого кооператива для RPG Maker MZ. Код плагина и сервер размещаются отдельно от файлов конкретной игры.

## Текущий прототип

1. Подключение к серверу комнаты по WebSocket.
2. Видимый персонаж другого игрока на той же карте, передача позиции, направления и графики.
3. Комнаты с назначением хоста, обработкой входа и выхода, переподключением.
4. Host-authoritative синхронизация переключателей, переменных и self-switches.
5. Первый слой host-authoritative запуска событий, блокировка повторного запуска и локальное исключение через `<CoopLocal>`.
6. Автоматические тесты серверной комнаты, протокола событий и mock-runtime-поведения плагина.

Код всё ещё является прототипом, не готовым кооперативным релизом. Автоматические тесты успешно прошли на коммите 2a070fc (14/14); позже обновлённая документация также прошла CI. Синхронизация switch/variable ранее проверена владельцем в двух клиентах. Первый слой модели событий маршрутизирует запуск к хосту, но пока не транслирует гостям диалоги, выборы, предметы, бои или переходы карты, вызванные event-командами. См. [архитектуру](docs/ARCHITECTURE.md).

## Проект для совместимости

Первичный тестовый проект, предоставленный владельцем: **Michael Way – Double Way**, RPG Maker MZ **1.10.0**. В полученном архиве список плагинов пуст, присутствует карта Map001. Игровые данные и ресурсы проекта не копируются в этот репозиторий.

## Структура

- `plugin/` — JavaScript-плагин для RPG Maker MZ.
- `server/` — отдельный Node.js WebSocket-сервер комнат.
- `docs/` — архитектура, этапы, тесты и журнал наблюдений.
- `tests/` — автоматические проверки, которые могут выполняться без ручного запуска редактора.
- `tools/prepare-test-builds.js` — подготовка пары Host/Guest из одного Windows-экспорта, с актуальным плагином и отдельными NW.js-профилями.

## Подготовка тестовых сборок

После одного Windows-экспорта можно получить два одинаковых тестовых клиента без ручного редактирования двух проектов:

    node tools/prepare-test-builds.js --source "D:\\Path\\To\\WindowsExport" --output "D:\\Coop-Pl-Test\\Builds" --server-url "ws://127.0.0.1:8080" --room-code "TEST_ROOM"

Результат: `Builds/Host/Game.exe` и `Builds/Guest/Game.exe`; подробности находятся в [docs/TESTING.md](docs/TESTING.md).
